# 2026-11-04 本机混合负载验证

UTC 运行号 `20261104T010652Z`，提交 `eaac9e1`。被测服务与发压端共用一台 Windows 主机，Docker Linux 引擎 29.7.2，低内存 HA 配置包含八个应用 JVM、MySQL 三节点、Redis/Sentinel、RocketMQ、Nacos、双 SRS 和三个监控采集端。37 个运行容器的前后快照核对通过，应用实例、运行 JAR 和资源限制一致。
